Blogger Setup — OAuth Client ID

Step 1: Enable Blogger API

Go to console.cloud.google.com/apis/dashboard → Search Blogger API v3 → Enable.

If you want Blogger, you need JetTheme: Buy JetTheme — AMP story support.

Step 2: Create Web OAuth Client

  1. Credentials → Create Credentials → OAuth Client ID
  2. Application type: Web application
  3. Authorized JavaScript origins: https://clonner.in + your domain
  4. Authorized redirect URIs: same origins
  5. Copy Client ID: ...apps.googleusercontent.com

Step 3: Connect in StoryForge Settings (Live Screenshot)

Open https://clonner.in/settings.php or your domain /settings.php → Blogger connection → Paste Client ID → Connect Blogger → Google popup → Allow → Select blog → Save.

Live capture from localhost:8000/settings.php — shows Blogger + WordPress connection UI

WordPress Setup — Application Password

Step 1: Generate App Password in WP

WP Admin → Users → Profile → Application Passwords → New Application Password Name: 123 → Generate → Copy.

Step 2: Add in StoryForge (Live)

Settings → WordPress connection → Enter WP Site URL, Username, App Password → Save. Green Connected badge = ready.
