#🚀 Introducing StoryForge — Web Story Automation Platform

Maine ek complete Web Story Automation System build kiya hai jo story creation, AI writing, content scraping aur publishing workflow ko ek hi platform me bring karta hai.

##✨ Key Features
• 📝 Drag & Drop Web Story Builder
• 🤖 AI Story Writer with Groq
• 🔎 Sitemap & Content Scraper
• 📱 Mobile-friendly Story Canvas
• 🔗 Blogger OAuth Integration
• 🌐 WordPress Publishing Integration
• 👥 Silver / Platinum / Super Admin roles
• 💳 QR / UPI based payment & approval system
• 📚 Story Archive & History
• 🖼️ Image upload, Unsplash & URL support
• ⚡ PHP 8.4 + Playwright based automation
• 🔐 Sensitive credentials browser-side storage workflow

The entire documentation includes real localhost screenshots and live workflow recordings, so the features shown are based on the actual application rather than mockups.
